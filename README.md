## Run Locally

**Requirements:** Node.js (LTS recommended) and npm.

```bash
git clone https://github.com/Lokesh-81/lokesh.portfolio.git
cd lokesh.portfolio
npm install
npm run dev
```

The development server runs at [http://localhost:3000](http://localhost:3000).

For a production build:

```bash
npm run build
npm run preview
```

### Environment

Create a local `.env` file and configure the integrations you use. The project may use the following environment variables depending on the enabled features:

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
GEMINI_API_KEY=
APP_URL=
CRON_SECRET=
```

Use the exact values from your own service dashboards. Never commit private keys, service-role keys, passwords, or other secrets.
